نصائح المكياج والبشرة

كيف تختاري لون أحمر الشفاه المناسب للون بشرتك والمناسبة

بقلم براءة علي، خبيرة مكياج · ١١ تشرين الأول ٢٠٢٦

الجواب المختصر

اختاري أحمر الشفاه حسب تحت لون بشرتك: الدافي بتليق عليه درجات الكراميل والطوبي والمرجاني، والبارد بتليق عليه الدرجات الوردية والتوتية. وللمناسبات النهارية النود والوردي، وللسهرات الأحمر والخمري.

لون الشفايف ممكن يغيّر الإطلالة كلها. وهون بتعرفي كيف تختاري اللون المناسب إلك.

اعرفي تحت لون بشرتك

إذا عروق إيدك مخضرّة غالباً تحت لونك دافي، وإذا مزرقّة غالباً بارد، وإذا مش واضحة غالباً محايد.

للبشرة الدافية

الكراميل، الطوبي، المرجاني، والأحمر البرتقالي.

للبشرة الباردة

الوردي، التوتي، والأحمر المزرق.

حسب المناسبة

  • نهار وزيارات: نود أو وردي
  • سهرة: أحمر أو خمري
  • عروس: لون بيوازن مكياج العيون وبيطلع حلو بالصور

قاعدة التوازن

عيون قوية مع شفايف هادية، أو عيون هادية مع شفايف قوية.
